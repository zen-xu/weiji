# macOS 界面约定

界面优先使用系统控件、系统字体和用户的强调色。主任务是查看已归档通知和本机文件，默认页面应把空间留给内容。工具栏取舍参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/toolbars)。

应用中文名为“微迹”。窗口、菜单、关于面板、设置、启动引导和命令行帮助统一使用 `ApplicationInfo.name`；Bundle 显示名称与打包文件名保持一致。已有数据、签名身份及 MCP 接入标识继续沿用。

## 导航与操作

- 主窗口使用 `NavigationSplitView` 和原生 sidebar `List`。资料库、工具、会话分组展示；移除重复的应用标志、标语、会话头像底块和预览文字。
- 页面标题、搜索与常用操作进入原生窗口工具栏。通知页提供开始/暂停、刷新及导入导出菜单；文件和图片页提供选目录、扫描。
- 文件菜单提供导入通知、导出通知、关闭窗口；设置使用独立窗口，支持标准的 `⌘,`。主窗口关闭后仍留在菜单栏运行。
- 页底只显示数量、覆盖范围及分页，统一为 32 pt。复制等临时反馈自动消失，错误提示保留到手动关闭。

## 启动引导

- 正常启动先显示轻量检查页，不创建主界面内容。应用进程实际确认通知源可读后才继续，终端权限或旧的完成标记不能放行。
- 访问被拒绝时展示三步说明、系统权限设置入口、Finder 定位与重新检查。返回应用自动复查；系统要求重新启动应用时给出明确说明。源文件缺失、数据库忙或格式不兼容分别提示，不重复要求授权。
- 首次可读后显示简洁配置页：自动采集开关、可选文件目录和“开始使用”。保存成功才打开主界面；旧设置保留，完成后不重复配置。窗口从 600 pt 引导尺寸恢复到主界面保存的大小。
- 引导期间菜单中的采集、导入导出及设置不可用，尚未启动档案写入或目录扫描。HTTP MCP 自动启动，仍可读取已有档案。

## 内容展示

- 通知使用平铺的日期分组和细分隔线，保留会话、发送者及时间。私聊不重复显示同一联系人名称；会话名称仍可进入对应分组。
- 原始通知通过行操作菜单或右键菜单打开，支持复制正文、原始正文、JSON 和 ID。发送者的推测来源及未知会话分组提示保留。
- 普通文件使用原生 `Table`，支持名称、大小、日期列、选择、双击打开及右键 Finder 定位。文件候选仍明确标记归属未验证。
- 图片使用简洁网格；预览加载、无法读取、未解码分别展示。消息中的图片只保留必要的来源提示，文件名、时间差和其他版本折叠在详情中。
- 采集状态、MCP 接入和设置使用原生 grouped `Form`。默认显示状态和关键操作，配置文本、工具明细和长说明按需展开。

## 验证边界

1.6.0（build 12）包含权限优先的启动引导。17 组可执行的原生检查（含 9 组启动检查）、8 项签名配置检查及真实 HTTP MCP 检查通过；性能基准默认跳过。最终 release 产物打包和严格签名校验通过，产物的 HTTP 检查及 stdio 握手、六个工具、空档案状态和 EOF 检查也已通过。测试使用合成数据，记录见 [Validation.md](Validation.md)。

Mac 锁屏且用户暂时不在电脑旁，无法完成实际窗口中的点击、键盘导航、搜索焦点、设置窗口与弹出层检查，也尚未验证真实权限授予后的返回/重启流程。临时渲染器已检查权限引导和配置页、浅色/深色通知内容、文件表格、图片目录占位和 MCP 表单的离屏布局；系统侧边栏材质与部分原生控件无法完整捕获，不能据此认定完整窗口视觉验证通过。原有 3 组图片缓存读取测试同样仍受锁屏文件保护限制。

本轮仅生成新 `.app`，保留 `/Applications` 中运行的 1.5.0，待解锁后先检查上述交互再更新安装。档案格式、通知采集、文件读取边界及 HTTP MCP 地址保持兼容。
