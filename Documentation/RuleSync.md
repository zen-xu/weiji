# 通过 iCloud Drive 同步规则

微迹 0.4.0 起支持 iCloud Drive 文件夹同步。现有固定项目证书、Bundle ID 和数据目录保持不变。此方式使用用户选择的文件夹，不需要应用专用 iCloud 容器；不会自动读取、创建或上传到未经用户选择的 iCloud 路径。

## 开启

1. 在每台 Mac 登录同一个 Apple 账户，并在 Finder 确认 iCloud Drive 可用。
2. 打开“微迹 → 提醒规则…”，开启“iCloud Drive 同步”。
3. 在文件选择器中选择 iCloud Drive 内的同一个文件夹，例如专门创建的“微迹”。微迹在所选目录下创建“微迹提醒规则”子目录；其他 Mac 应选择同一层的“微迹”目录。
4. 之后规则变化自动合并；可以点“立即同步”。状态明确区分本地文件保存、等待 iCloud 上传和系统报告已上传。显示“已上传”也不代表其他设备已经收到。

同步默认关闭。只同步规则名称、条件、启停、安静时段、合并间隔，以及合并所需的因果版本和删除标记；不包含通知内容、提醒收件箱、联系人档案、图片、数据库、提示音、采集开关、磁盘权限或其他本机设置。规则本身可能包含群名、人名或关键词，开启后这些内容将由所选 iCloud Drive 文件夹同步。不要选择共享给其他人的文件夹，除非确实希望向这些人共享规则。

若选择普通本机目录，界面会明确提示确认其位于 iCloud Drive；本机文件夹本身不能跨设备传输。没有 iCloud 登录、网络断开或文件尚未下载时，本机规则仍可使用；应用运行并且文件恢复可用后重试。每台设备都需要开启此选项并运行微迹，iCloud Drive 的传输时机由 macOS 决定。

## 合并与冲突

- 每台安装使用随机副本 ID，各自写一个 `weiji-rules-<UUID>.json`，避免多台设备覆盖同一个共享文件。文件只包含紧凑的当前因果状态，无无限增长的编辑日志。
- 使用规则 ID 和因果版本合并，不按设备时间判胜负，系统时间不同不会导致旧规则胜出。独立规则的修改直接合并。
- 同一规则的并发修改保留一个确定的主版本，其他不同内容成为默认停用的“冲突副本”。检查后可编辑、启用或删除；后续编辑主版本不会悄悄删除这些副本。多个设备保存相同内容时不额外生成副本。
- 删除使用持久标记，旧设备重新上线不会复活旧版本。若删除与未见过的新编辑并发，原规则保持删除，新编辑以停用副本保留，避免未经检查再次提醒。
- iCloud 产生的未解决文件版本会先读入并合并，只有已写入本机状态及当前同步文件后才标记解决。无法读取、版本不支持、损坏或超限时不会把它当成空规则覆盖本机。
- 超过 32 条有效规则（含冲突副本）时，保留当前本机列表并显示原因，完整合并状态仍保存及传递；可在某台设备精简现有规则，删除仍传播，数量恢复后继续应用合并结果。最多 32 个副本、4096 个规则 ID（含删除标记）、单文件 16 MB；超限明确报错，关闭同步后仍可使用本机规则。

文件夹移动、删除、Apple 账户变化或书签失效时可能需要重新选择文件夹；应用不会自动退回路径并将旧账户规则上传到新的目标。关闭同步不删除本机规则或云端文件；关闭期间本机修改仍记为因果变更，以便重新开启后正确合并。不要通过删除同步 JSON 来删除某条规则，请在 App 或 MCP 中删除。

## 实现与验证边界

`NSFileCoordinator` 协调文件读写，`NSFilePresenter` 监听变化，60 秒容差计时器补漏，500 ms 合并连续请求；后台 utility 队列执行云端文件 I/O、解析和合并。内容不变时不重写文件，不产生循环上传。退出、换目录和关闭同步取消旧任务，不等待云端传输；本机规则写入与因果记录在既有锁和同一次原子替换中完成，因此 GUI 关闭时通过 stdio MCP 写规则也不会丢失离线修改。

本机的 `reminder-sync.json`（0600）只保存开关和用户选择文件夹的书签；不写入同步目录，不通过 MCP 返回。同步因果状态保存在既有 `reminder-rules.json`，MCP 输出仍只含原有 revision 和规则，客户端接口兼容。规则的条件 ID 变化不构成内容冲突。云端文件按 0600 创建。不会修改现有签名、公钥、系统信任、磁盘授权或图片保护。

合成测试覆盖两套独立本机数据目录与同一临时“云目录”的实际协调交换、合并收敛、重复投递、并发冲突、删除、离线 MCP 写入、修订冲突、损坏文件、取消、千次编辑后的状态大小、不变文件不重写、同步开关及窗口尺寸。它们验证同步协议与文件读写，不证明真实 Apple 账户的传输、跨 Mac 送达或 Finder 书签在账户切换后的行为。真实 iCloud Drive 双机测试与交互视觉检查需要在用户选择目录后另行验证；未自动启用真实同步或上传真实规则。
